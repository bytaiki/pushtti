# 製品仕様

[文書一覧](README.md) · [開発計画と検証](development-plan.md)

## 対象と操作

- 公開GitHubリポジトリを対象とするChrome拡張機能。
- リポジトリごとに「育てる」を押すとキャラが誕生する。
- 右下の固定ボタンからパネルを開き、キャラ・コメント・育成状況・歴代キャラを確認する。
- パネルを閉じている間はボタンだけを表示する。

## 餌と成長

| 活動 | 効果 |
| --- | --- |
| 人によるコミット1件 | 餌となり、経験値10を加算 |
| スター増加1件 | 経験値2を加算。生存期間は延長しない |

- 既定ブランチと作業ブランチを対象とし、GitHubへpushされたコミットを取得する。
- 同じ識別番号のコミットは1回だけ数える。コピーやまとめ直しで別の番号になったものは別扱いとする。
- Botと、合流だけのコミットは除外する。
- 誕生時は経験値0。誕生前のコミットや既存スターは加算しない。
- スターは、その世代で確認した最多数からの増分を加算する。

## 進化とキャラ

| 段階 | 累計経験値 | 姿 |
| --- | --- | --- |
| 幼体 | 0〜99 | 丸い体、大きな目、小さな手足 |
| 成長期 | 100〜499 | 手足が発達し、小さな角やしっぽが生える |
| 成体 | 500〜 | 発達した角や羽、凛々しい立ち姿 |

- 1系統・3段階で構成し、リポジトリごとの固定色を次世代にも引き継ぐ。
- 進化段階と体調は別に管理する。成体になった後も経験値は蓄積する。
- コメントは少し生意気でユーモアのある日本語。パネルを開いた時と、新しい餌・スター増加・進化・体調変化に反応する。

## 放置と世代交代

| 最後の餌からの期間 | 状態 |
| --- | --- |
| 7日未満 | 通常 |
| 7日以上、20日未満 | 寂しがる |
| 20日以上、30日未満 | 弱る |
| 30日以上 | 死亡 |

- 誕生または最後の餌を起点に、1日を24時間として数える。
- Chromeを閉じていても時間は進む。次の更新時に履歴をたどり、途中に30日間の空白があれば、その時点で死亡した扱いとする。
- 死亡後のコミットでは復活しない。「次世代を育てる」から新しい世代を始める。
- 歴代キャラの世代・誕生日・死亡日・到達した姿を残す。

## 更新と保存

- ページを開いた時、対象ページの表示中は15分ごと、手動更新時に情報を確認する。複数タブでも同じ活動を重複計上しない。
- 通信失敗や取得途中は確認待ちとし、履歴が揃う前に死亡を確定しない。
- 育成データはChrome内に保存する。端末間同期とバックアップは初版に含めない。
- 取得前に削除された作業ブランチなど、後から確認できないコミットは計上できない場合がある。

取得・保存・描画の仕組みは [技術一覧](../README.md#technologies) を参照。

## 今後の追加機能

- 自分のリポジトリだけを育成対象にする。
- 別リポジトリのキャラとの対戦。
- 開発者数に応じた成長値の補正。
- キャラの系統を追加する。
